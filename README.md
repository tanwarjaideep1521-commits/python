# Python Beginner Programs

A beginner-friendly Python repository containing simple programs to practice fundamental programming concepts, including factorial calculation, Fibonacci series generation, and dictionary operations using student information.

## 📌 Overview

This repository is designed for beginners who are starting their journey with Python programming. It contains basic programs that help develop logical thinking and understand essential Python concepts through practical examples.

### Programs Included

- **Factorial:** Calculates the factorial of a given number.
- **Fibonacci Series:** Generates a Fibonacci sequence up to a specified number of terms.
- **Student Dictionary:** Stores and manages student information using Python dictionaries.

## ⚙️ Requirements

To run these programs, you need:

- Python 3.x installed on your computer.
- A code editor such as VS Code or any text editor.
- A terminal or command prompt.

No external Python libraries are required.

To check whether Python is installed, run:

```bash
python --version
```

If that command does not work, try:

```bash
python3 --version
```

## 🚀 How to Run

**Step 1: Clone the repository**

```bash
git clone <repository-url>
```

Replace `<repository-url>` with your GitHub repository URL.

**Step 2: Open the project folder**

```bash
cd python-beginner-programs
```

**Step 3: Run the programs**

Run each program separately:

```bash
python factorial.py
```

```bash
python fibonacci.py
```

```bash
python student_dictionary.py
```

On systems where Python is invoked as `python3`, replace `python` with `python3`.
